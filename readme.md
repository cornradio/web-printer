> 由于德佟 P1 标签打印机官方的pc网页端打印效果很差，所以我写了这个项目。主要是使用 Atkinson 抖动算法+自定义曝光调整，打印图片效果更佳。

> 使用方法：下载项目文件后，安装驱动（printerHelper.exe），然后打开 test/html/index.html 文件，即可看编辑器。
